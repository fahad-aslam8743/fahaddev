# FahadDev v17 — Distinct Hero Visuals

This release focuses only on the hero direction requested after v16.

### What changed
- Real image-led hero backgrounds instead of coded abstract scenes.
- A genuinely different visual composition for every main page.
- Separate service-detail scenes.
- Mobile-specific versions of every hero image.
- Black headings retained for a premium editorial feel.
- Copy remains HTML layered over the background for accessibility and SEO.
- Work case studies can use each project's uploaded CMS image in the hero.

### Database
No new SQL is needed.

### Deployment
Use your existing environment variables. Run `npm install && npm run build`, then deploy normally.
