# FahadDev v21 — Distinct Hero Elements

This release stops reusing one hero visual system across the site.

## Hero artwork
Each main route now has its own element image:
- Home
- Services
- Work
- Process
- About
- Contact
- Privacy

Each service detail page also has its own dedicated image:
- E-commerce development
- Dashboards / internal tools
- Full-stack web apps
- Website improvements

Case studies continue to prefer the real project screenshot uploaded through Admin. If a project has no screenshot, Work artwork is used as the fallback.

## Responsive eyebrow fix
The small dotted label above hero titles is no longer a cramped pill. It is now a flexible dot + text row that can wrap without colliding on desktop or mobile.

## Mobile
Hero artwork remains visible as a compact preview below the CTAs rather than a second full-height hero.

No Supabase migration is required.
