# FahadDev v18 — Desktop Artwork / Text-only Mobile Heroes

This release keeps the distinct v17 hero artwork for desktop and removes it entirely on mobile.

## Hero behavior
- Desktop: generated hero art gets the majority of the hero canvas; copy is a tighter editorial column.
- Desktop readability overlay ends much earlier so the artwork remains visible.
- Headline and description sizing reduced so the hero art is not buried by copy.
- Laptop widths keep a two-part visual balance without allowing copy to spread across the image.
- Mobile: hero artwork is disabled completely. Visitors see eyebrow, headline, description and CTAs on a clean white surface.
- Mobile proof rows and service best-fit boxes are removed from the first screen to keep the hero concise.
- Small phones switch CTA buttons to a single-column stack.

No database or Supabase changes are required.
