# FahadDev v13 — Changelog

## Rolled back from the over-animated direction

- Removed the interaction language that felt childish, game-like or motion-heavy.
- Kept the proven business funnel, Admin, lead inbox, review moderation and project CMS.
- Rebuilt the public-facing experience as a white, modern studio site.

## Navigation

- New rounded floating navbar with breathing room from all viewport edges.
- Desktop navigation is compact and calm.
- Mobile hamburger reveals a contained dropdown directly below the navbar.
- Mobile links reveal downward one by one with a short stagger.
- Escape, backdrop click and route changes close the mobile menu.
- Route navigation now explicitly resets scroll to the top.

## Page and reveal motion

- Added a restrained route-entry transition.
- Scroll reveals use opacity + small vertical movement rather than blur-heavy effects.
- Motion follows reading and interaction rather than running constantly.
- Reduced-motion users receive a static experience.

## Hero system

All main public pages retain a hero and receive a distinct live visual:

- Home: customer-facing product plus connected CMS/orders/production state.
- Work: problem → system → outcome case-study view.
- Services: connected Interface/Data/Commerce/Operations/Launch system.
- Process: live Understand → Shape → Build → Review → Launch delivery path.
- About: direct-builder decision and ownership model.
- Contact: enquiry → context → scope → reply path with Email/WhatsApp.
- Privacy: project data handling and review moderation flow.

When the featured project has a CMS-uploaded image, Home uses the real screenshot automatically instead of a generic placeholder.

## Interactive sections

- Rebuilt the project-type explorer with E-commerce, Dashboard, Web App and Improve Existing modes.
- Each mode changes the visible product mock, customer outcomes, internal/team outcomes, signal path and relevant CTA.
- Rebuilt the delivery story as a sticky, scroll-linked product canvas.
- Added subtle live connector lines and interface states where they help explain a system.

## Copy and funnel clarity

- Tightened main hero copy around what the client receives.
- Work now frames projects around problem, system and outcome.
- Services now starts from the client's business need rather than technology names.
- Process explicitly makes decisions and progress visible.
- About emphasizes direct ownership and one-builder communication.
- Contact starts from the client's problem rather than requiring them to know the solution.

## Visual language

- White editorial surfaces with subtle cobalt/cyan accents.
- Less pill-heavy UI.
- Crisp buttons and disciplined card radii.
- Soft grid/line graphics used as supporting system visuals.
- Projects, FAQs and CTA areas simplified for a more premium studio rhythm.
- Mobile retains natural left alignment and calmer motion.

## Backend/admin

No schema or admin workflow changes are required in this release. v13 preserves the v10/v12 lead, review, project and upload systems.
